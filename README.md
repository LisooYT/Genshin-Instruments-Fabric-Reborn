## About

**Genshin Instruments Reborn** is an unofficial continuation of the Genshin Instruments Fabric mod.

The project aims to bring the instruments from Genshin Impact into Minecraft, preserving the original experience while updating the mod for newer Minecraft versions and modern Fabric environments.

This project exists to continue development, improve compatibility, fix bugs, and keep the mod accessible to players on newer versions of Minecraft.

### Features

- Genshin Impact-inspired instruments in Minecraft.
- Musical gameplay and instrument functionality from the original project.
- Continued compatibility updates for newer Minecraft versions.
- Bug fixes and maintenance.
- Improvements and quality-of-life changes where appropriate.

*Features may change as development progresses.*

## Reporting Bugs

Found a bug? Please open an issue on GitHub.

When reporting a problem, include as much information as possible:

- Minecraft version.
- Genshin Instruments Reborn version.
- Fabric Loader version.
- Fabric API version.
- Other installed mods, if relevant.
- Steps to reproduce the issue.
- What you expected to happen.
- What actually happened.

**Please attach your full `latest.log` or `debug.log` whenever possible.**

A detailed bug report makes it much easier to identify and fix problems.
