## About

**Genshin Instruments Reborn** is the revival and continuation of my previous Genshin Instruments Fabric project.

After the original project went unmaintained, this repository serves as a fresh start for development, with the goal of bringing Genshin Impact's instruments back to newer Minecraft versions.

The aim is to preserve the original experience while improving compatibility, fixing bugs, and continuing development for modern Fabric environments.

### Features

- Genshin Impact-inspired instruments in Minecraft.
- Musical gameplay and instrument functionality from the original project.
- Compatibility updates for newer Minecraft versions.
- Bug fixes and ongoing maintenance.
- Potential improvements and quality-of-life changes.

*Features may change as development progresses.*

## Reporting Bugs

Found a bug? Feel free to open an issue in the GitHub issue tracker.

When reporting a bug, please provide as much information as possible:

- Minecraft version.
- Genshin Instruments Reborn version.
- Fabric Loader version.
- Fabric API version.
- Other installed mods, if relevant.
- Steps to reproduce the issue.
- What you expected to happen.
- What actually happened.

**Please attach your full `latest.log` or `debug.log` whenever possible!**

Reports containing detailed information make diagnosing and fixing issues considerably easier.
